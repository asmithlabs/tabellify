# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report vulnerabilities privately through GitHub's private vulnerability reporting:
go to the [Security tab](https://github.com/asmithlabs/tabellify/security) of this repository
and choose **Report a vulnerability**.

Please include what you found, the Tabellify and Zotero versions, and steps to reproduce
(using a test Zotero profile, not real data). You will get an acknowledgement as soon as
possible; fixes are released as a new version and summarized in the changelog once fixed.

## Supported versions

| Tabellify version | Supported |
|---|---|
| Latest release | Yes |
| Older releases | No — please update to the latest release |

Tabellify supports the Zotero versions listed in its `manifest.json` (currently Zotero 10.0.x).

## Scope

Tabellify is a Zotero plugin. Problems in Zotero itself should be reported to Zotero
(<https://www.zotero.org/support/>).
