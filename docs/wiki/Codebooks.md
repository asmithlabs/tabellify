# Codebooks

> **Planned (Feature F004).** Not available in Tabellify 0.1.0.

A codebook is a curated (preplanned) list of tags you intend to use while reading the papers
in a collection. The plan is that you can create a codebook in Tabellify and group its tags
under **super-tags**, which later become grouped column headers in a table. The codebook is
stored by Tabellify itself; your Zotero tags stay unchanged.

Details will be written here when the feature is specified. Roadmap and product decisions:
[product requirements](https://github.com/asmithlabs/tabellify/blob/main/docs/product-requirements.md).
