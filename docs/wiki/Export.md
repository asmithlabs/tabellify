# Export

> **Planned (Feature F008).** Not available in Tabellify 0.1.0.

Export is planned to save a table as a **CSV** file you can open in a spreadsheet or another
app, with Excel (XLSX) as an optional later step. Files will be written only to a location
you choose.

Details will be written here when the feature is specified. Roadmap:
[product requirements](https://github.com/asmithlabs/tabellify/blob/main/docs/product-requirements.md).
