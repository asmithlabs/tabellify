# Tabellify

Tabellify is a Zotero plugin that turns the tags on your highlights into a literature table
(a synthesis matrix), so you can organize, compare and export research findings.

You plan a list of tags (a codebook) and tag the highlights in your papers with them in
Zotero's reader. Tabellify then shows a table: one row per paper, one column per tag, and a ✓
where the paper uses the tag. Tabellify never changes your Zotero library.

Version **0.1.0** works with **Zotero 10.0.x**.

## What Tabellify can do

- Open its own **Tabellify** tab in the main Zotero window from **Tools → Tabellify…**.
- Show the papers of any collection in My Library, including its subcollections.
- Keep a codebook of planned tags, with optional groups, typed in one line.
- Suggest your existing Zotero tags while you type.
- Count which codebook tags each paper uses, in the Tabellify tab and in a
  **Tabellify tags** section beside the reader.
- Sort the table, put papers in your own order, move columns and regroup tags by dragging.
- Follow Zotero's light or dark look.
- Show the finished table with **View table**, with a Name and a Description.
- Save tables and open them later, as saved or rebuilt from your library now.
- Export any table as a CSV file for Excel, Numbers, R or Python.

## Coming later

- Highlight text in table cells, instead of a ✓.
- More column options, such as your own columns.
