# Table Builder

> **Planned (Feature F006).** Not available in Tabellify 0.1.0.

The table builder is planned to turn a collection and its tags into a literature table:
one row per paper, columns for tags grouped under super-tags, with a preview grid. Product
decisions already recorded: by default a cell shows the text of highlights carrying that
tag, and the table can use item tags, annotation tags, or both.

User-created and reorderable columns are a separate later feature (**Planned, F009**, column
customization).

Details will be written here when the feature is specified. Roadmap and decisions:
[product requirements](https://github.com/asmithlabs/tabellify/blob/main/docs/product-requirements.md).
