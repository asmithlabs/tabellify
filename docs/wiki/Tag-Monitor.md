# Tag Monitor

> **Planned (Feature F005).** Not available in Tabellify 0.1.0.

The tag monitor is planned to show, for a collection, which tags from your
[codebook](Codebooks) you have already used and which remain (for example "Tags used 4/15"),
so you know when you have covered every planned tag.

Where it appears and how it counts tags will be decided in its feature spec. Roadmap:
[product requirements](https://github.com/asmithlabs/tabellify/blob/main/docs/product-requirements.md).
