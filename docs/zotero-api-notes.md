# Verified Zotero API notes

Every Zotero/Mozilla API used in `src/` must appear here with a source link and the Zotero
versions it was verified against. Status values: **Verified (docs)**, **Verified (source)**,
**Verified (runtime)**, **UNVERIFIED**.

- **Verified (docs)**: stated in an official zotero.org developer page.
- **Verified (source)**: read in the Zotero (or Mozilla ESR) source at the stated tag.
- **Verified (runtime)**: the owner ran it in the Zotero dev profile (see "Runtime checks
  for owner" below). Agents never assign this status.
- Interim wording **"Verified (source); RT… passed (owner run <date>) — runtime status pending
  owner sign-off"**: the owner ran a check and an agent recorded the result, but the owner has
  not yet changed the status to Verified (runtime).
- **Internal** (extra marker): not in any zotero.org developer guide (Z7, Z8, Z9, Z10
  checked). Zotero can change it in any release without notice. Used only where an accepted
  ADR allows it (for `Zotero_Tabs`: ADR-0009).
